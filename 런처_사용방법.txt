damagoch.dogi 런처 사용 방법

1. 이 ZIP을 풉니다.
2. 압축을 푼 파일 전체를 하나의 무료 호스팅 사이트에 올립니다.
3. 런처 주소를 Android Chrome 또는 iPhone Safari로 엽니다.
4. Android는 '런처 설치' 또는 Chrome 메뉴의 '앱 설치'를 누릅니다.
5. iPhone은 Safari 공유 버튼 > 홈 화면에 추가를 누릅니다.

처음 설정
- 런처 설정 패스키: bidolgidamagoch
- 기본 게임 주소는 https://steady-daifuku-d02fd8.netlify.app/ 로 설정되어 있습니다.
- 게임 주소가 바뀌면 런처 설정에서 새 주소만 입력하면 됩니다.
- 런처를 다시 설치할 필요가 없습니다.

게임 업데이트
1. 최신 게임 ZIP을 기존 게임 사이트에 덮어쓰기 배포합니다.
2. 게임 사이트 최상위에 version.json을 함께 올립니다.
3. 런처가 version.json을 확인해 새 버전을 감지합니다.
4. 사용자는 '업데이트 후 실행'을 누르면 최신 게임을 불러옵니다.

중요
- 런처 자체와 게임 사이트는 서로 다른 주소여도 됩니다.
- Firebase 데이터와 관리자 UID는 게임 사이트의 Firebase 설정을 그대로 사용합니다.
- 게임 주소가 바뀌어도 런처 설정에서 주소만 수정하면 됩니다.
- iPhone은 자동 설치창을 띄울 수 없으므로 Safari의 홈 화면에 추가를 사용합니다.
